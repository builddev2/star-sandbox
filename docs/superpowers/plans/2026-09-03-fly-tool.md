# Fly Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a steerable spacecraft with maneuver nodes, a delta-v budget, a Hohmann transfer solver and a gravity-assist overlay, drawn as a space shuttle.

**Architecture:** A new headless physics module `src/maneuver.py` holds every piece of orbital arithmetic; `Simulation` executes due burns inside the substep loop; a new `FlyTool` in `src/app/tools.py` describes the panel and draws the overlay. The craft is a new one-way body kind with its own material and sprite. Nothing new is invented where `src/orbits.py` already has it — `propagate`, `conic_points`, `elements_from_state` and `dominant_attractor` do the heavy lifting.

**Tech Stack:** Python 3.11, numpy, pygame 2.6. Tests are pytest.

**Spec:** `docs/superpowers/specs/2026-09-03-fly-tool-design.md`

## Global Constraints

Copied verbatim from `CLAUDE.md` and the spec. Every task's requirements implicitly include this section.

- **Simulation units are AU, solar masses, days.** `src/units.py` is the single source of truth for `G` and every conversion factor. **No other module may define one.**
- **`src/*.py` must never import pygame.** `tests/test_layering.py` asserts it in a subprocess. `src.maneuver` MUST be added to its `PHYSICS_MODULES` list.
- **Never hold an array index across a frame.** Store `body.id` and resolve through `World.index_of(id)`, which returns `None` when the body is gone.
- **Every mutation of mass, radius or membership must be followed by `Simulation.refresh()`.**
- **`World.contact_radius` is not `World.radius`.** Only the yes/no "did these two touch" test uses `contact_radius`. Every outcome uses true `radius`.
- **Physics never reads a *visual* radius.** `render/scale.visual_radii` is for drawing, picking and the contact refresh only.
- **Every action has a button, and every button carries its hotkey.** `tests/test_ui.py` reads the shortcut list out of `hud.KEY_HELP` and fails if any documented key has no button.
- **A hotkey does not inherit a control's `enabled` gate.** Keyboard events bypass `UiLayer.perform`'s `clickable` check, so a key path must duplicate any precondition the control carries.
- **A tool panel row is not free.** `tests/test_layout.py` checks a tool panel stops above the transport bar at `config.min_internal(3)`, where there is room for **six rows and no more**. The Fly panel is exactly six rows.
- **A tool never draws its own buttons or hit-tests the mouse.** It returns `controls()` rows and implements `perform()`; `ui.py` lays out, draws and dispatches.
- **Nothing may cache a size across frames.**
- **Angles are radians everywhere** except the source data tables in `src/scenarios.py`.
- Tests that touch pygame set `os.environ.setdefault("SDL_VIDEODRIVER", "dummy")` at module top, **before** importing pygame.
- Run the suite with `./.venv/bin/python` if the system Python lacks pygame/numpy.

```python
"""Steering a craft: a burn, planned before it happens.

A **maneuver node** is a point on the craft's own predicted orbit plus the
impulse to apply there.  That is the whole idea, and it is what turns a
gravity simulator into a spaceflight simulator: you pick a point, say how
hard to burn, and see the new orbit *before* committing to it.

``due_time`` is absolute world days rather than a countdown, so it does not
have to be rewritten every frame as the clock advances; the countdown the
panel shows is ``due_time - world.time``, computed where it is displayed.

Everything here is two-body algebra about whatever ``orbits.dominant_attractor``
says the craft is orbiting.  That is exact for the ordinary case -- a craft
and a planet both going round the same star -- and a good estimate otherwise,
which is the same trade ``LaunchTool``'s aiming preview already makes.

Imports numpy and nothing from pygame -- ``tests/test_layering.py`` asserts it.
"""

import math
from dataclasses import dataclass

import numpy as np

from . import orbits, units


@dataclass(frozen=True)
class Maneuver:
    """One impulsive burn.  Speeds are AU/day; the panel scrubs them in m/s.

    Frozen for the same reason ``Body.locked_fields`` is a frozenset:
    rebinding is then the only way to change a node, so two craft can never
    end up sharing one mutable object.
    """

    due_time: float
    #: Along the velocity vector.  Negative is retrograde.
    prograde: float = 0.0
    #: Along the radius vector, away from the attractor.  Negative is inward.
    radial: float = 0.0

    @property
    def magnitude(self):
        """Total delta-v this burn spends, AU/day."""
        return math.hypot(self.prograde, self.radial)


def craft_state(world, index):
    """``(attractor, mu, rel_pos, rel_vel)`` for a body, or None if it has no
    attractor -- which happens only when it is the most massive thing present.
    """
    attractor = orbits.dominant_attractor(world, index)
    if attractor is None:
        return None
    mu = units.G * (float(world.mass[attractor]) + float(world.mass[index]))
    return (attractor, mu,
            np.array(world.pos[index] - world.pos[attractor], dtype=float),
            np.array(world.vel[index] - world.vel[attractor], dtype=float))


def node_state(world, index, node):
    """``(mu, rel_pos, rel_vel)`` at the node, *before* the burn.

    Propagated on the craft's own two-body orbit, exactly -- ``orbits.propagate``
    converts to mean anomaly, advances it linearly and converts back, which is
    correct for a bound orbit and a hyperbolic one alike.  A node already due
    is evaluated where the craft is now.
    """
    state = craft_state(world, index)
    if state is None:
        return None
    _attractor, mu, rel_pos, rel_vel = state
    dt = float(node.due_time) - float(world.time)
    if dt <= 0.0:
        return mu, rel_pos, rel_vel
    pos, vel = orbits.propagate(mu, rel_pos, rel_vel, dt)
    return mu, np.asarray(pos, dtype=float), np.asarray(vel, dtype=float)


def burn_velocity(rel_pos, rel_vel, node):
    """The relative velocity after ``node``'s impulse is applied.

    Prograde is along the velocity, radial along the position -- the two
    directions a flat orbit offers.  A zero-length vector contributes nothing
    rather than a divide by zero.
    """
    pos = np.asarray(rel_pos, dtype=float)
    vel = np.asarray(rel_vel, dtype=float)
    out = vel.copy()

    speed = float(np.hypot(vel[0], vel[1]))
    if speed > 0.0 and node.prograde != 0.0:
        out = out + (vel / speed) * node.prograde

    distance = float(np.hypot(pos[0], pos[1]))
    if distance > 0.0 and node.radial != 0.0:
        out = out + (pos / distance) * node.radial

    return out


def plan_conics(world, index, plan, samples=160):
    """``(attractor, [(points, bound), ...])`` -- the orbit after each node.

    Each conic is relative to the attractor, so a caller adds the attractor's
    position before projecting.  Node *k*'s conic is propagated from node
    *k-1*'s post-burn state, which is what makes a two-burn transfer draw as
    the two arcs it really is.
    """
    state = craft_state(world, index)
    if state is None:
        return None, []
    attractor, mu, rel_pos, rel_vel = state

    conics = []
    clock = float(world.time)
    for node in plan:
        dt = float(node.due_time) - clock
        if dt > 0.0:
            rel_pos, rel_vel = orbits.propagate(mu, rel_pos, rel_vel, dt)
            rel_pos = np.asarray(rel_pos, dtype=float)
            rel_vel = np.asarray(rel_vel, dtype=float)
            clock = float(node.due_time)
        rel_vel = burn_velocity(rel_pos, rel_vel, node)
        conics.append(orbits.conic_points(mu, rel_pos, rel_vel, samples=samples))
    return attractor, conics
```

```python
def closest_approach(mu, craft_pos, craft_vel, target_pos, target_vel,
                     horizon_days, samples=240):
    """How near the craft and the target ever get, within ``horizon_days``.

    Both are propagated on their own two-body orbits about the same attractor
    and sampled at the **same instants**.  Time is the only parameterisation
    that lets two different orbits be compared: sampling each by true anomaly
    would compare a point on one orbit against a point on the other that the
    bodies never occupy together.

    A coarse sweep finds the best sample, then one refinement pass looks
    inside the neighbouring interval, which is enough because separation is
    smooth in time and the coarse grid already brackets the minimum.
    """
    craft_pos = np.asarray(craft_pos, dtype=float)
    craft_vel = np.asarray(craft_vel, dtype=float)
    target_pos = np.asarray(target_pos, dtype=float)
    target_vel = np.asarray(target_vel, dtype=float)

    def separation(dt):
        c_pos, c_vel = orbits.propagate(mu, craft_pos, craft_vel, dt)
        t_pos, t_vel = orbits.propagate(mu, target_pos, target_vel, dt)
        gap = float(np.hypot(c_pos[0] - t_pos[0], c_pos[1] - t_pos[1]))
```

```python
def hohmann(mu, r1, r2, theta_craft, theta_target):
    """The two burns of a Hohmann transfer, **and when to start it**.

    The two delta-v figures are the easy half and every textbook has them.
    The half that actually matters when you try to fly one is ``wait_days``:
    a transfer only arrives somewhere useful if the target is where the craft
    is going when it gets there, so the departure has to wait for the phase
    angle to come round.  That is a launch window, and it is why missions to
    Mars leave every twenty-six months rather than whenever they are ready.

    Angles are radians measured about the attractor, in the direction of
    motion.  Returns speeds in AU/day, signed: negative is a retrograde burn,
    which is what going *inward* costs.
    """
    r1, r2 = float(r1), float(r2)
    a_transfer = 0.5 * (r1 + r2)

    v1 = math.sqrt(mu / r1)
    v2 = math.sqrt(mu / r2)
    depart = v1 * (math.sqrt(2.0 * r2 / (r1 + r2)) - 1.0)
    arrive = v2 * (1.0 - math.sqrt(2.0 * r1 / (r1 + r2)))
    transfer = math.pi * math.sqrt(a_transfer ** 3 / mu)

    # The target must lead the craft by this much at departure, so that half
    # an orbit of the transfer ellipse later the two arrive together.
    n1 = math.sqrt(mu / r1 ** 3)
    n2 = math.sqrt(mu / r2 ** 3)
    required = math.pi - n2 * transfer
    current = float(theta_target) - float(theta_craft)

    rate = n2 - n1
    if abs(rate) < 1e-15:
        wait = 0.0
    else:
        delta = (required - current) % (2.0 * math.pi)
        if rate < 0.0:
            # The target is falling behind, so the gap has to close the other
            # way round; shifting into (-2pi, 0] keeps the wait positive.
            delta -= 2.0 * math.pi
        wait = delta / rate

    return {"depart_dv": depart, "arrive_dv": arrive,
            "transfer_days": transfer, "wait_days": max(0.0, wait),
            "a_transfer": a_transfer}
```

```python
def flyby(mu_planet, v_inf, periapsis):
    """How much a planet bends a passing craft, and where it leaves.

    A flyby is a hyperbola about the planet.  The speed the *planet* sees --
    ``v_inf`` -- is exactly the same going out as coming in; all the planet
    does is rotate it, by

        e = 1 + r_p |v_inf|^2 / mu,     delta = 2 asin(1/e)

    and that rotation is the whole gravity assist.  The craft gains nothing
    relative to the planet and everything relative to the star, because the
    rotated ``v_inf`` adds to the planet's own orbital motion differently
    than the original did.  That is why the drawing is a triangle: nothing
    about it is a fudge.
    """
    v = np.asarray(v_inf, dtype=float)
    speed2 = float(v[0] * v[0] + v[1] * v[1])
    if speed2 <= 0.0 or periapsis <= 0.0 or mu_planet <= 0.0:
        return {"e": math.inf, "turn": 0.0, "v_out": v.copy()}

    e = 1.0 + float(periapsis) * speed2 / float(mu_planet)
    turn = 2.0 * math.asin(min(1.0, 1.0 / e))

    cos_t, sin_t = math.cos(turn), math.sin(turn)
    return {"e": e, "turn": turn,
            "v_out": np.array([cos_t * v[0] - sin_t * v[1],
                               sin_t * v[0] + cos_t * v[1]])}
```

```python
def apply_burn(world, index, node):
    """Fire ``node`` on the body at ``index`` now.  True if anything happened.

    A burn that costs more than the tank holds is **scaled down to what is
    left** rather than refused.  Running out mid-burn is what really happens,
    and it teaches more than a control that silently does nothing.

    The impulse is added in the world frame: the attractor's own velocity is
    in both the before and after relative velocities, so it cancels, and a
    craft orbiting a moving planet gets the right answer for free.
    """
    state = craft_state(world, index)
    if state is None:
        return False
    _attractor, _mu, rel_pos, rel_vel = state

    body = world.bodies[index]
    wanted = node.magnitude
    if wanted <= 0.0:
        return False

    budget = float(body.fuel_dv)
    if budget <= 0.0:
        return False
    fraction = 1.0 if wanted <= budget else budget / wanted
    spent = Maneuver(node.due_time, node.prograde * fraction,
                     node.radial * fraction)

    world.vel[index] += burn_velocity(rel_pos, rel_vel, spent) - rel_vel
    body.fuel_dv = max(0.0, budget - spent.magnitude)
    return True


def next_burn_time(world):
    """The soonest ``due_time`` anywhere in the world, or infinity.

    ``Simulation`` caches this so the substep loop is one float comparison
    rather than a scan over every body: at ten years a second the integrator
    takes thousands of substeps a frame, and a Python loop over 200 bodies
    inside it would eat the wall-clock budget many times over.
    """
    soonest = math.inf
    for i in range(world.n):
        plan = world.bodies[i].plan
        if plan:
            soonest = min(soonest, float(plan[0].due_time))
    return soonest


def execute_due(world, now=None):
    """Fire every node whose time has come.  Returns how many were popped.

    A node is popped whether or not the burn could be applied, so a craft
    that has lost its attractor cannot jam the queue forever.
    """
    when = float(world.time) if now is None else float(now)
    fired = 0
    for i in range(world.n):
        body = world.bodies[i]
        while body.plan and float(body.plan[0].due_time) <= when:
            node = body.plan[0]
            body.plan = body.plan[1:]
            apply_burn(world, i, node)
            fired += 1
    return fired
```

```python
            # caps the craft's contact radius, and a shuttle should be hard
            # to hit rather than easy.
```

```python
    Drawn nose-along-+x from polygons and then rotated, which is both cheaper
    and steadier than re-deriving every vertex per angle: the outline is
```

```python
#: How far ahead of the body it launches from a craft is placed, as a
#: fraction of that body's own orbital radius.  Far enough that the two are
#: visibly separate at system zoom, near enough that a transfer from here is
#: the same transfer the body itself would fly.
LAUNCH_OFFSET = 0.02


class FlyTool(Tool):
    name = "Fly"
    hint = ("Pick a body and press Launch  -  then set a burn and watch the new "
            "orbit appear before you commit to it  -  X locks a target, "
            "M works out the transfer for you")
    context_title = "Fly"

    #: The rows the panel scrubs, in order.  Up/Down picks one.
    FIELDS = ("when", "prograde", "radial")
    #: Notches one press of a stepper applies.  All three move three at a
    #: time: a single 10 m/s notch is invisible against a 3,000 m/s burn.
    CLICK_NOTCHES = {"when": 3, "prograde": 3, "radial": 3}

    def __init__(self):
        self.field_index = 0
        self.target_id = None
        self.picking_target = False
        self._drag_x = None

    # --- what we are flying -----------------------------------------------------

    def _craft(self, state):
        """The selected body if it is a craft, otherwise None.

        Deliberately not "the last craft launched": the selection is already
        how everything else in the interface says what it acts on, and a tool
        that silently acts on something other than what is selected is the
        kind of thing that makes a sandbox feel haunted.
        """
        body = state.selected_body
        return body if body is not None and body.kind == KIND_CRAFT else None

    def _node(self, state):
        craft = self._craft(state)
        if craft is None or not craft.plan:
            return None
        return craft.plan[0]

    def _target_index(self, world):
        """Row of the locked target, clearing the lock if it is gone."""
        if self.target_id is None:
            return None
        index = world.index_of(self.target_id)
        if index is None:
            self.target_id = None
        return index

    # --- launching --------------------------------------------------------------

    def _launch(self, state):
        """Put a craft in orbit beside the selected body.

        **Around whatever that body orbits, not around the body itself.**  A
        parking orbit 300 km above Earth has a ninety-minute period, and
        ``Integrator.dynamical_time`` takes the tightest pair in the *entire*
        system: one craft in low orbit would drive the block level to its
        ceiling and step the whole solar system in units of seconds.  The six
        existing moons already cost a factor of 64 in step size; this would be
        far worse.  Starting co-orbital costs nothing and is the right frame
        for an interplanetary transfer anyway.
        """
        world = state.sim.world
        index = state.selected_index
        if index is None or world.n >= world.capacity:
            return None

        attractor = orbits.dominant_attractor(world, index)
        if attractor is None:
            return None

        rel = world.pos[index] - world.pos[attractor]
        radius = float(np.hypot(rel[0], rel[1]))
        if radius <= 0.0:
            return None

        # A small rotation ahead of the parent, on the same circle.
        angle = LAUNCH_OFFSET
        cos_a, sin_a = math.cos(angle), math.sin(angle)
        offset = np.array([cos_a * rel[0] - sin_a * rel[1],
                           sin_a * rel[0] + cos_a * rel[1]])

        mu = units.G * float(world.mass[attractor])
        speed = math.sqrt(mu / radius)
        tangent = np.array([-offset[1], offset[0]]) / radius
        # Match the parent's own sense of rotation.
        parent_vel = world.vel[index] - world.vel[attractor]
        if float(np.dot(tangent, parent_vel)) < 0.0:
            tangent = -tangent

        body = world.add("Shuttle", materials.SPACECRAFT,
                         units.EARTH_MASS * 1e-18, units.CRAFT_RADIUS,
                         world.pos[attractor] + offset,
                         world.vel[attractor] + tangent * speed,
                         kind=KIND_CRAFT,
                         temperature=float(world.temperature[index]))
        if body is None:
            return None
        body.fuel_dv = units.from_ms(units.DEFAULT_FUEL_MS)
        state.select(body.id)
        state.sim.refresh()
        return body
```

```python
#: One notch of the delta-v steppers, m/s.  Linear rather than a ratio: a
#: burn runs from tens of m/s to a few thousand, which is two decades, not
#: the eight that mass covers.
DV_NOTCH_MS = 10.0
#: One notch of the node-time stepper, as a ratio.  The countdown has to span
#: minutes to years, so it scrubs the way mass does.
TIME_NOTCH_RATIO = 1.06
#: The shortest a node can be set to.
MIN_LEAD_DAYS = 0.01


def scrub_dv(speed, notches):
    """Move a delta-v component by ``notches`` of DV_NOTCH_MS."""
    return speed + units.from_ms(DV_NOTCH_MS * notches)


def scrub_lead(days, notches):
    """Move a countdown by ``notches``, multiplicatively.  Never past zero."""
    days = max(float(days), MIN_LEAD_DAYS)
    return max(MIN_LEAD_DAYS, days * TIME_NOTCH_RATIO ** notches)
```

```python
    def _default_lead(self, state):
        """Where a fresh node lands: a quarter of the way round the orbit.

        Far enough ahead to be worth planning, near enough to arrive while
        anyone is still watching.
        """
        index = state.selected_index
        if index is None:
            return 30.0
        facts = orbits.dominant_attractor(state.sim.world, index)
        if facts is None:
            return 30.0
        world = state.sim.world
        mu = units.G * (float(world.mass[facts]) + float(world.mass[index]))
        el = orbits.elements_from_state(
            mu, world.pos[index] - world.pos[facts],
            world.vel[index] - world.vel[facts])
        period = el["period"]
        return 30.0 if period is None else max(0.5, period * 0.25)

        craft = self._craft(state)

            craft.plan = (maneuver.Maneuver(due_time=due),)

        target = self._target_index(world)

        when = ("--" if node is None
                else _lead_label(node.due_time - world.time))
        prograde = ("0 m/s" if node is None
                    else "%+,.0f m/s" % units.to_ms(node.prograde))
        radial = ("0 m/s" if node is None
                  else "%+,.0f m/s" % units.to_ms(node.radial))

        def stepper(cid, label, row):
            return [
                Control(cid, icon="minus", payload=-1, compact=True, repeat=True,
                        enabled=has_craft, active=self.field_index == row,
                        tooltip="Less"),
                Control(cid + ".readout", label=label, readout=True),
                Control(cid, icon="plus", payload=1, compact=True, repeat=True,
                        enabled=has_craft, active=self.field_index == row,
                        tooltip="More"),
            ]

        return [
            [Control("fly.launch", label="Launch craft", icon="fly",
                     enabled=state.selected_index is not None,
                     tooltip="Put a shuttle in orbit beside what you picked"),
             Control("fly.refuel", label="Refuel", icon="reset",
                     enabled=has_craft, tooltip="Fill the tank back up")],
            [Control("fly.target", label=self._target_label(state), icon="target",
                     hotkey="X", active=self.picking_target or target is not None,
                     tooltip="Click a body to measure your approach to it")],
            stepper("fly.when", "When  %s" % when, 0),
            stepper("fly.prograde", "Along  %s" % prograde, 1),
            stepper("fly.radial", "Out    %s" % radial, 2),
            [Control("fly.hohmann", label="Work out the transfer", icon="flyto",
                     hotkey="M", enabled=has_craft and target is not None,
                     tooltip="Plan the two burns that get you there"),
             Control("fly.clear", icon="close", hotkey="N", compact=True,
                     enabled=has_craft and node is not None,
                     tooltip="Throw the plan away")],
        ]

    def perform(self, control, state):
        cid = control.id
        if cid == "fly.launch":
            self._launch(state)
            return True
        if cid == "fly.refuel":
            craft = self._craft(state)
            if craft is not None:
                craft.fuel_dv = units.from_ms(units.DEFAULT_FUEL_MS)
            return True
        if cid == "fly.target":
            self.picking_target = not self.picking_target
            return True
        if cid == "fly.clear":
            craft = self._craft(state)
            if craft is not None:
                craft.plan = ()
                state.sim.refresh()
            return True
        if cid == "fly.hohmann":
            self._plan_transfer(state)
            return True
        if cid in ("fly.when", "fly.prograde", "fly.radial"):
            field = cid.split(".", 1)[1]
            self.field_index = self.FIELDS.index(field)
            self._scrub(state, field,
                        int(control.payload) * self.CLICK_NOTCHES[field])
            return True
        return False

    def _scrub(self, state, field, notches):
        node = self._ensure_node(state)
        if node is None:
            return
        world = state.sim.world
        if field == "when":
            lead = maneuver.scrub_lead(node.due_time - world.time, notches)
            node = maneuver.Maneuver(world.time + lead, node.prograde, node.radial)
        elif field == "prograde":
            node = maneuver.Maneuver(node.due_time,
                                     maneuver.scrub_dv(node.prograde, notches),
                                     node.radial)
        else:
            node = maneuver.Maneuver(node.due_time, node.prograde,
                                     maneuver.scrub_dv(node.radial, notches))
        self._replace_node(state, node)

    def _plan_transfer(self, state):
        """Fill the plan with the two burns of a Hohmann transfer."""
        craft = self._craft(state)
        world = state.sim.world
        index = state.selected_index
        target = self._target_index(world)
        if craft is None or index is None or target is None:
            return

        state_now = maneuver.craft_state(world, index)
        if state_now is None:
            return
        attractor, mu, rel_pos, _rel_vel = state_now
        if target == attractor:
            return

        target_rel = world.pos[target] - world.pos[attractor]
        r1 = float(np.hypot(rel_pos[0], rel_pos[1]))
        r2 = float(np.hypot(target_rel[0], target_rel[1]))
        if r1 <= 0.0 or r2 <= 0.0:
            return

        solved = maneuver.hohmann(
            mu, r1, r2,
            math.atan2(float(rel_pos[1]), float(rel_pos[0])),
            math.atan2(float(target_rel[1]), float(target_rel[0])))

        depart = world.time + solved["wait_days"]
        craft.plan = (
            maneuver.Maneuver(depart, solved["depart_dv"], 0.0),
            maneuver.Maneuver(depart + solved["transfer_days"],
                              solved["arrive_dv"], 0.0),
        )
        state.sim.refresh()
```

```python
def _lead_label(days):
    """A countdown in whatever unit keeps the number readable."""
    if days < 0.0:
        return "now"
    if days < 1.0:
        return "%.1f hr" % (days * 24.0)
    if days < 2.0 * units.DAYS_PER_YEAR:
        return "%,.0f d" % days
    return "%.1f yr" % units.to_years(days)
```

```python
    # --- overlay ----------------------------------------------------------------

    #: How long an encounter result stays good, milliseconds.  The search is a
    #: few hundred Kepler propagations; recomputing it every frame for every
    #: candidate would be felt.  Invalidated immediately by any change to the
    #: plan, the selection or the target -- this only bounds how stale a
    #: result can get while the world moves underneath an unchanged plan.
    ENCOUNTER_TTL_MS = 200

    def _encounter_key(self, state):
        craft = self._craft(state)
        if craft is None:
            return None
        return (craft.id, self.target_id, craft.plan)

    def _encounter(self, state):
        """Closest approach to the locked target under the current plan, cached."""
        key = self._encounter_key(state)
        if key is None or self.target_id is None:
            self._encounter_cache = None
            return None

        now = pygame.time.get_ticks()
        cached = getattr(self, "_encounter_cache", None)
        if (cached is not None and cached[0] == key
                and now - cached[1] < self.ENCOUNTER_TTL_MS):
            return cached[2]

        world = state.sim.world
        index = state.selected_index
        target = self._target_index(world)
        state_now = maneuver.craft_state(world, index) if index is not None else None
        if state_now is None or target is None:
            self._encounter_cache = (key, now, None)
            return None

        attractor, mu, rel_pos, rel_vel = state_now
        clock = float(world.time)
        for node in self._craft(state).plan:
            dt = float(node.due_time) - clock
            if dt > 0.0:
                rel_pos, rel_vel = orbits.propagate(mu, rel_pos, rel_vel, dt)
                clock = float(node.due_time)
            rel_vel = maneuver.burn_velocity(rel_pos, rel_vel, node)

        target_rel_pos = world.pos[target] - world.pos[attractor]
        target_rel_vel = world.vel[target] - world.vel[attractor]
        lead = max(0.0, clock - float(world.time))
        if lead > 0.0:
            target_rel_pos, target_rel_vel = orbits.propagate(
                mu, target_rel_pos, target_rel_vel, lead)

        el = orbits.elements_from_state(mu, rel_pos, rel_vel)
        horizon = el["period"] if el["period"] is not None else 2000.0
        result = maneuver.closest_approach(mu, rel_pos, rel_vel,
                                           target_rel_pos, target_rel_vel,
                                           horizon_days=min(horizon, 4000.0),
                                           samples=200)
        result["attractor"] = attractor
        result["mu"] = mu
        result["start_day"] = clock
        self._encounter_cache = (key, now, result)
        return result

    def draw_overlay(self, surface, state, font):
        craft = self._craft(state)
        world = state.sim.world
        camera = state.camera

        target = self._target_index(world)
        if target is not None:
            tx, ty = camera.world_to_screen(world.pos[target])
            pygame.draw.circle(surface, palette.SELECT, (int(tx), int(ty)), 6, 1)

        if craft is None:
            return

        index = state.selected_index
        attractor, conics = maneuver.plan_conics(world, index, craft.plan,
                                                 samples=160)
        if attractor is not None:
            origin = world.pos[attractor]
            for k, (points, bound) in enumerate(conics):
                if len(points) < 2:
                    continue
                projected = camera.world_to_screen_array(points + origin)
                np.clip(projected, -32000, 32000, out=projected)
                colour = palette.ACCENT if k == 0 else palette.TRAIL_BASE
                pygame.draw.lines(surface, colour, bool(bound),
                                  projected.astype(int).tolist(), 1)

        node = self._node(state)
        if node is not None:
            found = maneuver.node_state(world, index, node)
            if found is not None and attractor is not None:
                _mu, node_pos, _node_vel = found
                nx, ny = camera.world_to_screen(node_pos + world.pos[attractor])
                pygame.draw.circle(surface, palette.SELECT, (int(nx), int(ny)), 4, 1)
                pygame.draw.line(surface, palette.SELECT,
                                 (int(nx) - 6, int(ny)), (int(nx) + 6, int(ny)), 1)

        self._draw_readout(surface, state, font, craft, node)
        self._draw_assist(surface, state, font)

    def _draw_readout(self, surface, state, font, craft, node):
        """Fuel, the countdown, and where the plan puts you."""
        world = state.sim.world
        x, y = 8, 34
        line = font.height + 2

        fuel_ms = units.to_ms(craft.fuel_dv)
        font.draw(surface, x, y, "Fuel   %,.0f m/s" % fuel_ms,
                  palette.WARN if fuel_ms < 500.0 else palette.TEXT)
        bar = pygame.Rect(x, y + line - 2, font.width("X") * 16, 3)
        widgets.draw_bar(surface, bar,
                         fuel_ms / max(units.DEFAULT_FUEL_MS, 1.0), palette.ACCENT)
        y += line * 2

        if node is not None:
            font.draw(surface, x, y, "Burn in %s"
                      % _lead_label(node.due_time - world.time), palette.TEXT)
            y += line
            found = maneuver.node_state(world, state.selected_index, node)
            if found is not None:
                mu, pos, vel = found
                el = orbits.elements_from_state(
                    mu, pos, maneuver.burn_velocity(pos, vel, node))
                font.draw(surface, x, y, "Closest  %s"
                          % hud.format_length(el["periapsis"]), palette.TEXT_DIM)
                y += line
                farthest = ("never returns" if el["apoapsis"] is None
                            else hud.format_length(el["apoapsis"]))
                font.draw(surface, x, y, "Farthest %s" % farthest,
                          palette.TEXT_DIM)
                y += line

        encounter = self._encounter(state)
        if encounter is not None:
            font.draw(surface, x, y, "Passes %s at %s"
                      % (world.bodies[self._target_index(world)].name,
                         hud.format_length(encounter["distance"])),
                      palette.AIM_GOOD)

    def _draw_assist(self, surface, state, font):
        """The velocity triangle at a flyby.

        |v_inf| is the same going out as coming in; all the planet does is
        rotate it.  Drawing the two heliocentric velocities and their
        difference is what makes that visible, and the speeds beside them are
        what make it a lesson rather than a decoration.
        """
        encounter = self._encounter(state)
        if encounter is None:
            return
        world = state.sim.world
        target = self._target_index(world)
        if target is None:
            return

        primary = float(world.mass[encounter["attractor"]])
        distance = float(np.hypot(*encounter["target_pos"]))
        hill = units.hill_radius(float(world.mass[target]), primary, distance)
        if encounter["distance"] > hill or encounter["distance"] <= 0.0:
            return

        v_craft = encounter["craft_vel"]
        v_planet = encounter["target_vel"]
        v_inf = v_craft - v_planet

        mu_planet = units.G * float(world.mass[target])
        turned = maneuver.flyby(mu_planet, v_inf, encounter["distance"])
        v_out = v_planet + turned["v_out"]

        camera = state.camera
        origin = camera.world_to_screen(
            encounter["craft_pos"] + world.pos[encounter["attractor"]])

        # One pixel scale for all three arrows, so the triangle closes.
        span = max(float(np.hypot(*v_craft)), 1e-12)
        pixels = 46.0 / span

        def arrow(vec, colour):
            end = (origin[0] + float(vec[0]) * pixels,
                   origin[1] - float(vec[1]) * pixels)
            pygame.draw.line(surface, colour,
                             (int(origin[0]), int(origin[1])),
                             (int(end[0]), int(end[1])), 1)
            return end

        arrow(v_planet, palette.TEXT_DIM)
        tip_in = arrow(v_craft, palette.ACCENT)
        arrow(v_out, palette.AIM_GOOD)

        font.draw(surface, int(tip_in[0]) + 4, int(tip_in[1]),
                  "in  %s" % hud.format_speed(float(np.hypot(*v_craft))),
                  palette.ACCENT)
        font.draw(surface, int(tip_in[0]) + 4, int(tip_in[1]) + font.height + 1,
                  "out %s" % hud.format_speed(float(np.hypot(*v_out))),
                  palette.AIM_GOOD)
```

**Deviation from the spec, recorded deliberately:** the spec put the craft's
minimum drawn size in `visual_radii`. That array also feeds `contact_radii_au`,
so a radius large enough to draw a readable shuttle would also give the craft a
contact radius of millions of kilometres. Task 7 therefore splits it: a modest
`craft_apparent_radius()` in `visual_radii` for picking and contact, and a
render-only `CRAFT_MIN_PX` floor in `draw.py` for the picture. The spec's intent
-- drawing, picking and contact all reading one helper, physics reading none of
them -- is preserved.

**Type consistency:** `Maneuver(due_time, prograde, radial)` is constructed
positionally in Tasks 6, 9 and 10 and by keyword in Task 2; both match the
dataclass field order. `craft_state` returns a 4-tuple everywhere it is
unpacked (Tasks 2, 6, 9, 10). `plan_conics` returns `(attractor, conics)` and is
unpacked that way in Tasks 2 and 10. `closest_approach` returns the same six
keys in Tasks 3 and 10, plus the three the caller adds in Task 10.
